# Project Overview

Vedha GlucoCare is a health application project intended to support glucose tracking and patient workflows. Confirm product scope and clinical claims with the project owner.

Historical technology notes: Java/Spring Boot backend, PostgreSQL, backend directory `/opt/vedhaglucocare/vedhaglucocare-backend`, port `8081`, Kubernetes namespace `veda-glucocare`. These are not verified current deployment facts.

Areas discussed: patient identity/authenticated workflows, glucose readings, appointment booking, PostgreSQL persistence, containers, and Kubernetes. This summary does not prove features are complete, tested, or deployed.
